# Segurança

Não abra issue pública para falhas de segurança.

Para relatar uma vulnerabilidade, use o recurso "Report a vulnerability" do GitHub
neste repositório (aba Security). Se ele não estiver disponível, entre em contato com
o mantenedor pelo perfil do GitHub.

Informe versão, passos para reproduzir e impacto. Não envie segredos, tokens ou dados
pessoais no relato.
